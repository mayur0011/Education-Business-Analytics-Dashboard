# Education-Business-Analytics-Dashboard
An end-to-end Power BI analytics platform built for an education business to provide real-time visibility into key operational and financial metrics. The project integrates 10 relational data tables into a unified, optimized data model using Power Query for data cleaning, transformation, and relationship mapping. 
A multi-page executive dashboard was designed to track critical business KPIs including:

Revenue performance
Admissions trends
Placements outcomes
Lead generation and conversion
The model is powered by 20+ custom DAX measures driving KPI cards, trend visuals, and dynamic slicers to support data-driven decision-making.

Technologies / Tools Used:

Power BI
Power Query
DAX (Data Analysis Expressions)
